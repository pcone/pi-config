### Task Summary

**One-sentence description**: Collapse the two implementation tiers into a single `implement-pro` agent running `deepseek/deepseek-v4-flash-0731`; delete `implement-flash` and its routing references.

**Goal**: A repo where exactly one implementation agent exists (`implement-pro`, model `deepseek/deepseek-v4-flash-0731`), all routing/work-order/agent-definition references to the two-tier split are gone, decisions and docs record the change, and the reviewer decorrelation + review gate still function identically.

**Rationale (record in decision doc)**: 0731's served-model AA indices (49.9/69.1/45.7) beat V4 Pro (44.3/59.4/36.4) on all three axes at ~⅓ the price ($0.019 vs $0.055 blended). Independent agentic evidence: DeepSWE — a third-party DataCurve benchmark (deepswe.datacurve.ai), NOT a DeepSeek internal eval — shows the 0731 build at 54.4 vs the April preview's 7.3, run on the SWE-bench authors' own `mini-swe-agent` harness held fixed across models; DataCurve positions it as harder than SWE-bench Pro (half-length prompts, 5.5× more code, verifier-audited, contamination-resistant). Note DeepSWE's absolute scale runs lower than SWE-bench Pro (harder corpus), so 54.4 is not directly comparable to the 55.4 SWE-Pro composite value. SWE-Pro/LCB remain unpublished for 0731 — this is a deliberate **experiment** with a documented rollback (revert two model lines). `math-algo-oracle` stays on `deepseek/deepseek-v4-pro` (its LCB/IMO advantage is measured; 0731's is not).
