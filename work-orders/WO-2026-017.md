### Task Summary

**One-sentence description**: Double the timeline's time resolution by rendering each column as two half-cells (`▌` earlier / `▐` later) using half-width block characters, moving the user-vs-LLM state distinction from glyph (v1's `▒` dither) to color (bright accent vs darkened accent).

**Goal**: The row becomes a 2W-column logarithmic timeline packed two-per-physical-column, keeping the approved 3-state mapping (user = bright, llm-only = dark, inactive = empty) per half-cell.

### Implementation Specification

**Detailed requirements**:

**1. Half-cell mapping (v2 scale).** Virtual resolution V = 2·W. For any age:

```
v = timelineColumn(ageMs, 2 * width)        // existing function, V substituted for W
k = Math.floor(v / 2)                        // physical column
h = v % 2                                    // 0 = left half (earlier), 1 = right half (later)
```

Sanity anchors (must hold): age = MIN_AGE_MS → v = 2W−1 → (W−1, 1) = rightmost column, right half (now is the right edge). Age = WINDOW_MS → v = 0 → (0, 0) = leftmost column, left half.

**2. `export type TimelineCell`** becomes:

```ts
export type TimelineCell = {
	left: "bright" | "dark" | "none";   // earlier sub-slot
	right: "bright" | "dark" | "none";  // later sub-slot
	isSessionStart: boolean;
};
```

The v1 `status: "solid" | "half" | "empty"` field is gone — this is a deliberate spec change (v1→v2), not test-gaming.

**3. `export function computeTimelineCells(entries, nowMs, width, sessionStartMs)`** — returns exactly `width` cells. Per in-range message entry (same filtering as v1: skip unparseable timestamps, exclude `nowMs − ts ≥ WINDOW_MS`, ignore non-message entries and unknown roles):

- `v = timelineColumn(ageMs, 2*width)`, `k = floor(v/2)`, `h = v % 2`.
- Role `user` → that half's state becomes `"bright"` (terminal — never downgraded).
- Role in `{assistant, toolResult, bashExecution}` → that half's state becomes `"dark"` only if currently `"none"` (bright wins).
- Marker: if `sessionStartMs !== undefined` and `nowMs − sessionStartMs < WINDOW_MS`, compute `v` for the start age and set `cells[floor(v/2)].isSessionStart = true` (computed once, applied last; column-level, unchanged from v1).

**4. `export function rgbToHsl(r, g, b)`** — standard algorithm, returns `{ h: number; s: number; l: number }` with h ∈ [0, 360), s/l as percentages (0–100), matching `hslToAnsiFg`'s parameter convention.

**5. `export function darkenAccentFg(theme: Theme): string | null`** — the darkened accent ANSI code, or null when unreachable:

- Extend the local `Theme` type in the file with optional members: `getFgAnsi?: (color: string) => string; getColorMode?: () => "truecolor" | "256color"` (defensive: absent on stubs/future versions → null).
- `const ansi = theme.getFgAnsi?.("accent")`. If missing → null.
- If `ansi` matches `/^\\x1b\\[38;2;(\\d+);(\\d+);(\\d+)m$/` → RGB → `rgbToHsl` → `hslToAnsiFg(h, s, Math.max(15, l * 0.5))` → return that ANSI string (same hue/saturation, ~half lightness).
- Otherwise (default color `\x1b[39m`, 256-color `38;5`, anything else) → null. Callers then fall back to `theme.fg("dim", …)`.

**6. `export function renderTimelineRow(cells, theme, width, darkFg?: string)`** — exactly `width` visible columns. `darkFg` is the darkened-accent ANSI code (computed once by the caller via `darkenAccentFg`); when undefined, compute it internally. Per column, in order:

1. `isSessionStart` → `theme.fg("warning", "\u2588")` (█) — column-level override, unchanged from v1.
2. both halves `"none"` → `" "`.
3. exactly one half active → `theme.fg("accent", "\u258c")` (▌, left) or `theme.fg("accent", "\u2590")` (▐, right) when that half is `"bright"`; when `"dark"`, render the same char with the dark color: `darkFg ? darkFg + char + "\x1b[39m" : theme.fg("dim", char)`.
4. both halves active → `\u2588` (█) in the winning state: `"bright"` if either half is bright, else `"dark"` (v1 precedence preserved).
5. `width < 1` → `""`; defensive pad/truncate to `width` as v1 (cells.length mismatch tolerated).

Dark char + ANSI reset: the existing session-words code establishes the raw-ANSI convention (`\x1b[39m` reset after custom fg codes) — follow it.

**7. `render()` wiring (unchanged shape).** The call site becomes:

```ts
const startMs = resolveSessionStartMs(sm.getHeader()?.timestamp, allEntries);
const cells = computeTimelineCells(allEntries, Date.now(), width, startMs);
const darkFg = darkenAccentFg(theme);
lines.push(renderTimelineRow(cells, theme, width, darkFg));
```

No new timers; `now = Date.now()` at render time; row stays the final footer line.
