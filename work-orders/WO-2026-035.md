### Task Summary

**One-sentence description**: Make `preCommitSteps` skip auto-committing carried files whose worktree bytes still match the carried-in snapshot, so a subagent that only *read* the orchestrator's uncommitted doc produces no branch commit.

**Goal**: When `createWorktree` carries the parent's uncommitted state into the worktree (WO-2026-034), the completion auto-commit must not commit files the subagent never touched (e.g. the plan doc it read). Only the subagent's actual changes — edits to carried files, new files, deletions it made — land on the branch. A subagent that carries a doc and reads it without editing should produce NO commit (branch stays at parent HEAD, and the existing `postDeliveryCleanup` then deletes the branch).

### Implementation Specification

**1. Snapshot type and capture.** Add a module-level type:

```ts
/** Per-path snapshot of the carried state; the completion filter compares
 *  the worktree against this to find files the subagent never touched. */
type CarriedEntry = { state: "present"; hash: string } | { state: "absent" };
type CarriedSnapshot = Map<string, CarriedEntry>;
```

Change `carryUncommittedState(topLevel, worktreePath): Promise<void>` → `Promise<CarriedSnapshot>` (returns a fresh empty map when `git status` fails / no changes — never null). While carrying each entry, record:
- present file (regular): `hash` = sha256 hex of the exact bytes written into the worktree (read the source bytes once: `readFileSync` → hash → `writeFileSync` → `chmodSync`; or keep `copyFileSync` and hash a separate read — pick one, document it in the KEEP IN SYNC contract).
- symlink: `hash` = `"link:" + readlink target` (same string written via `symlinkSync`).
- absent entries (deletions, rename-original paths): `{ state: "absent" }`.
- `.git` paths and unsafe paths are skipped as today and are NOT in the snapshot.
- Keep the existing copy semantics unchanged (exec bit, symlink-as-link, `-uall -z` parsing, R/C two-token handling) — do not re-litigate 034.

**2. `createWorktree` return.** Add an optional field: `carried?: CarriedSnapshot` — present (possibly empty map) when the overlay ran; absent when skipped (`carryUncommitted:false` or `baseRef`) or when `git status` failed. The existing three fields stay unchanged.

**3. Plumbing.** Call site (~line 2125): pass `wt.carried` into `spawnSubagent` as a new trailing optional param `carriedSnapshot?: CarriedSnapshot`. Store on `rs.carried` (add `carried: CarriedSnapshot | null` to `RunningSubagent`, default `null`). `preCommitSteps` reads `rs.carried`.

**4. The filter** — in `preCommitSteps`, AFTER the `WO-*.md` unstage block, BEFORE the `git diff --cached --quiet` check:

```ts
// Carried files that are byte-identical to what was carried in are the
// parent's state, not the subagent's work — don't commit them.
const carried = rs.carried;
if (carried && carried.size > 0) {
    const untouched: string[] = [];
    for (const [rel, snap] of carried) {
        const abs = path.join(worktreePath, rel);
        if (snap.state === "absent") {
            if (!fs.existsSync(abs)) untouched.push(rel);
        } else {
            const cur = hashCarriedFile(abs);
            if (cur === snap.hash) untouched.push(rel);
        }
    }
    if (untouched.length > 0) {
        await git(["reset", "-q", "--", ...untouched], worktreePath);
    }
}
```

`git reset -q -- <rel>` restores the index entry for that path to HEAD, so it also unstages carried *deletions* (file absent on branch). Args-array call handles spaces in paths. Any carry/compare failure inside the loop must NOT abort `preCommitSteps` (wrap the loop in try/catch; on error log via `debugLog` and continue with the untouched list computed so far).

**5. Hash helper.** Extract a module-scope helper used by BOTH capture and compare (single source of truth — this is the KEEP IN SYNC anchor):

```ts
/** sha256 hex of a file's bytes, or `"link:" + target` for a symlink,
 *  or null when the path is absent / not a regular file or symlink. */
function hashCarriedFile(absPath: string): string | null
```

Use `crypto` (already imported? check — `node:crypto` is imported as `randomUUID`; extend the import or add `createHash`). Symlink handling must match capture exactly (same `"link:"` prefix). `null` result (path gone) never equals a `"present"` snapshot hash → correctly treated as touched.

**6. Tests** — `test-completion-filter.cjs`, mirroring the filter per the KEEP IN SYNC contract (comment both sides). Use real temp repos, real `git worktree add`, real `git add -A` / `git reset` / `git diff --cached` (follow `test-carry-uncommitted.cjs`'s harness style: `execFileSync`, assert, PASS/FAIL tally, exit code). Matrix:

| # | Case | Expected |
|---|------|----------|
| 1 | Carried file read-only (never edited) | not in `git diff --cached`; no commit produced |
| 2 | Carried file edited by subagent | in `git diff --cached`; committed |
